# DogMail — 配布物置き場

[DogMail](https://github.com/MitamaHaruki/Dog-Mail) のインストーラを置くためのリポジトリです。
**ソースコードはここにはありません**（別の非公開リポジトリにあります）。

アプリの［設定］→［システム］→［更新］は、ここのリリースを見て新しい版が出ていないか確かめます。

## ダウンロード

[Releases](../../releases) から最新の `.msi` を取得してください。

## 入れる前に知っておいてほしいこと

- **アルファ版です。** 動作の保証はありません。
- **コード署名をしていません。** Windows 11 の「スマート アプリ コントロール」が
  有効な PC では「安全でない可能性のあるアプリをブロックしました」と出て起動できません。
  回避方法はありません。
- **PC 単位のインストール**です。実行すると途中で管理者権限を求められます。
- アカウント設定とキャッシュは `%APPDATA%\DogMail` と `%LOCALAPPDATA%\DogMail` にあり、
  アンインストールしても残ります。
